# Bank Management System

A console-based Bank Management System developed using C++.

## Overview

This project simulates a banking management system with user authentication, role-based permissions, and banking operations.

It allows administrators to manage system users and control their access to different operations based on assigned permissions.

## Features

### User Management
- Add new system users.
- Update user information.
- Delete users.
- View and manage user accounts.
- User authentication and login.

### Permissions System
- Assign specific permissions to each user.
- Control access to system features.
- Restrict operations based on user permissions.

### Banking Operations
- Create bank accounts.
- View client information.
- Deposit money.
- Withdraw money.
- Transfer money between accounts.
- Check account balances.
- List registered clients.

## Getting Started

### Prerequisites
- Visual Studio 2022 or a compatible C++ compiler.

### Run the Project

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the `.sln` file in Visual Studio 2022.

3. Build the solution.

4. Run the application.

## Project Purpose

This project was developed to strengthen C++ programming skills and practice object-oriented programming, file handling, user management, and permission-based access control through a practical banking system simulation.
